# SEC2.1 — фактические показатели Reader

Статус: реализован; независимое ревью APPROVED.

## План

1. Backend-кодер: учёт фактического чтения и Go-тесты.
2. Frontend-кодер: подключение HttpAdapter к существующим полям Reader и тесты.
3. TESTER при необходимости проверяет только frontend в браузере. Go и integration tests выполняет backend-кодер с сохранением stdout/stderr/exit codes; LEAD и другие роли их не повторяют. Затем read-only ревью и отдельный commit/push.

## Контракт и поведение

- Snapshot: `readerReadTps` — строки/с за последний фактический интервал; `readerRowsRead` — строки с начала запуска; `readerSource` — последний файл с прочитанными строками, путь с `/`, до чтения и после Reset — `null`.
- Строки считаются сразу после `reader.Read`, до enqueue, включая повторное чтение файла и строки вместе с EOF. Источник соответствует последнему чтению с n > 0.
- Первый интервал скорости начинается при Run. Pause сохраняет прогресс; producer дочитывает до заполнения очереди, затем скорость становится нулевой. Run продолжает, Reset обнуляет после завершения producer.
- Frontend берёт показатели из Go. Его изменения в пределах SEC2.1 прямо разрешены владельцем.

## Приёмка

- Реальное чтение Parquet, скорость за разные интервалы, согласованность счётчика и источника.
- Run → Pause → Run → Reset и HTTP snapshot.
- Поля Reader в backend UI, валидация HttpAdapter, frontend tests/build/lint.

Остальные подпункты roadmap, копирование batch и ошибки Reader после старта не входят в SEC2.1.

## Результат проверки

- Backend-кодер: `go test ./... -timeout 30s` и `go test -tags=integration ./... -timeout 30s` прошли; stdout/stderr и exit codes сохранены в runtime.
- Frontend-кодер: 280 тестов, build и lint прошли; проверены HttpAdapter и существующие строки инспектора.
- Независимый REVIEWER проверил весь diff и путь HTTP → HttpAdapter → UI; замечаний, требующих исправления, нет.
- TESTER не запускался: отдельного риска отображения не выявлено, React-компоненты не менялись. Browser smoke не выполнялся. LEAD и REVIEWER тесты не повторяли.
- `-race` недоступен в локальной среде (CGO отключён, gcc отсутствует); синхронизация дополнительно проверена ревьюером по коду.
