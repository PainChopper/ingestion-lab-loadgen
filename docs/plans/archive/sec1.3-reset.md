# SEC1.3 — Reset остановленного запуска

Статус: завершён.

## Контракт

- Из `paused` Reset завершает producer, отбрасывает очередь и переводит запуск в `idle` с нулевыми счётчиками текущего запуска.
- Из `idle` Reset допустим и оставляет чистое состояние.
- Из `running` Reset отклоняется без изменения запуска; HTTP возвращает 409.
- После Reset следующий Run создаёт новый producer и не получает батчи прежнего запуска.
- Prometheus counter остаётся накопительным за жизнь процесса; текущая скорость становится нулевой.

## Выполнено

1. Добавлены тесты сброса из `paused` и отказа из `running`.
2. Producer реагирует на отмену контекста; при Reset цикл дожидается закрытия канала и очищает очередь.
3. Счётчики запуска обнуляются, а результат Reset передаётся HTTP handler.
4. `go test ./... -timeout=30s`, 20 повторов тестов Reset и HTTP-команды и `git diff --check` прошли; проведено независимое ревью корректности и идиоматичности.

Frontend не менялся. Состояние `resetting` остаётся внутренним и не выдаётся в snapshot.
